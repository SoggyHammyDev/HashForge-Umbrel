# Experimental standalone package

Do not deploy to production yet. This branch uses a local Bitcoin Core image build, a dedicated archival data directory and generated RPC credentials. No host RPC or ZMQ ports are published. The node joins a dedicated bridge only; the pool joins both that bridge and the Umbrel application network. The bridge permits outbound peer connections and publishes no host ports. This is Docker-level isolation, not protection against the host administrator or privileged containers. The smoke test checks the node network and port configuration. The existing pool image is unchanged. The smoke test overrides the network to regtest. A publishable multiarchitecture image, setup UI, import integration and real Umbrel tests remain required. Do not upgrade a production installation from this branch.
